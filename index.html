FAQs

How does URL shortening work? −

URL shortening works by taking a long URL and creating a shorter, condensed version that redirects to the original URL. When a user clicks on the shortened link, they are seamlessly redirected to the intended destination.

Is it necessary to create an account to use the URL shortening service? +

No, you can shorten links right away without an account. However, creating a free account unlocks custom aliases, link analytics, and QR code management.

Are the shortened links permanent? Will they expire? +

All links generated on Scissor are permanent by default and do not expire unless you choose to set an expiration date or delete them from your dashboard.

Are there any limitations on the number of URLs I can shorten? +

Free users can shorten an unlimited number of URLs. Upgrading to our Professional or Teams tiers unlocks enhanced rate limits for API integrations and high-volume link generation.

Can I customize the shortened URLs to reflect my brand or content? +

Yes! You can customize both the domain (e.g. yourbrand.link) and the alias slug to reflect your specific campaign, product, or social profile.

Can I track the performance of my shortened URLs? +

Absolutely. Scissor provides in-depth analytics including click counts, geographic distribution, referral sources, and device types in real-time.

How secure is the URL shortening service? Are the shortened links protected against spam or malicious activity? +

We implement active malware detection, SSL encryption, and automated phishing protection to ensure all shortened URLs are safe for both creators and visitors.

What is a QR code and what can it do? +

A QR code is a machine-readable barcode that smartphones can scan to open your links instantly, ideal for print materials, packaging, events, and in-person marketing.

Is there an API available for integrating the URL shortening service into my own applications or websites? +

Yes, we offer a comprehensive REST API with official SDKs for Python, Node.js, and PHP to seamlessly embed link shortening and analytics directly into your product.
